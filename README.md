## 📈 ส่วนที่ 1: แบบจำลองการถดถอย (Regression Model)

### 1.1 แนวคิด ปัญหา และประโยชน์ในการนำไปใช้ (Concept & Problem Statement)
* **ปัญหาที่ต้องการแก้:** ค่าใช้จ่ายในการรักษาพยาบาลและค่าเบี้ยประกันสุขภาพรายปี (Health Insurance Charges) มีความผันผวนสูงมากตามปัจจัยสุขภาพและพฤติกรรม โดยเฉพาะการสูบบุหรี่และภาวะน้ำหนักเกิน หากประเมินคลาดเคลื่อนอาจทำให้บริษัทประกันขาดทุนหรือตั้งราคาไม่เป็นธรรมต่อผู้เอาประกัน
* **สิ่งที่ต้องการทำนายและหน่วย:** ค่าใช้จ่ายเบี้ยประกันสุขภาพรายปีรายบุคคล มีหน่วยเป็น **บาท (THB)** *(แปลงจากฐานข้อมูล $ USD ด้วยอัตราแลกเปลี่ยนอ้างอิงมาตรฐาน 1 USD = 35 บาท เพื่อให้สอดคล้องกับบริบทการใช้งานในประเทศไทย)*
* **ตัวแปรนำเข้า (Input Features: 6 ตัวแปร):**
  1. `age`: อายุของผู้เอาประกัน (18 - 80 ปี)
  2. `sex`: เพศสภาพ (`male`, `female`)
  3. `bmi`: ดัชนีมวลกาย ($kg/m^2$)
  4. `children`: จำนวนบุตรหรือผู้อยู่ในความอุปการะ (0 - 5 คน)
  5. `smoker`: ประวัติการสูบบุหรี่ (`yes`, `no`)
  6. `region`: ภูมิภาคที่อยู่อาศัยในสหรัฐฯ (`northeast`, `northwest`, `southeast`, `southwest`)
* **ประโยชน์ในการนำไปใช้:**
  * **บริษัทประกันภัย (Underwriting & Risk Pricing):** ใช้ประเมินความเสี่ยงและตั้งราคาเบี้ยประกันสุขภาพที่สะท้อนต้นทุนจริง (Risk-based Pricing)
  * **ประชาชนทั่วไป:** วางแผนงบประมาณสุขภาพในหน่วยเงินบาท และตระหนักถึงผลกระทบทางการเงินของการสูบบุหรี่และภาวะอ้วน

### 1.2 แหล่งที่มาและการแบ่งชุดข้อมูล (Dataset & Splitting)
* **แหล่งที่มา:** Medical Cost Personal Datasets (1,338 แถว, 7 คอลัมน์ สะอาด 100% ไม่มี Missing Values) เก็บไว้ในโฟลเดอร์ `data/insurance.csv`
* **การแบ่งชุดข้อมูล (80:20):**
  * Training Set (80%): **1,070 ตัวอย่าง**
  * Test Set (20%): **268 ตัวอย่าง** (ซ่อนไว้สำหรับวัดผลการทำนายจริง โดยใช้ `random_state=42`)

### 1.3 แบบจำลองที่ใช้และการประเมินผล (Model & Evaluation)
* **การเตรียมข้อมูล (Preprocessing Pipeline):** ตัวเลขผ่าน `StandardScaler`, ตัวแปรกลุ่มผ่าน `OneHotEncoder(drop='first')`
* **ผลการประเมินบนชุดทดสอบ (Test Set: 268 รายการ):**

| แบบจำลอง (Regression Model) | R² Score | RMSE (บาท) | MAE (บาท) | สรุปผล |
| :--- | :---: | :---: | :---: | :--- |
| **🏆 Gradient Boosting (โมเดลหลัก)** | **0.8792 (87.9%) 🚀** | **151,591.35 บาท** | **85,617.10 บาท** | **แม่นยำสูงสุด ดักจับ Non-linear Interaction ได้ดีเยี่ยม** |
| **🌲 Random Forest Regressor** | **0.8714** | 156,357.49 บาท | 89,263.19 บาท | เสถียรสูง ทนทานต่อ Outliers |
| **⚡ Linear Regression (Baseline)** | **0.7836** | 202,869.96 บาท | 146,341.81 บาท | เร็ว แต่ไม่สามารถจับปฏิสัมพันธ์แบบไม่เป็นเส้นตรงได้ |

* **การแปลความหมายเมตริกและวิเคราะห์ข้อผิดพลาด:**
  * โมเดล Gradient Boosting สามารถอธิบายความแปรปรวนของค่าเบี้ยประกันได้ถึง **87.92%**
  * ความคลาดเคลื่อนสัมบูรณ์เฉลี่ย (MAE) อยู่ที่ **85,617.10 บาท** (ต่ำมากเมื่อเทียบกับค่าเบี้ยประกันเฉลี่ยที่ ~464,450 บาท)
  * ตัวแปรที่สำคัญที่สุดคือ `smoker` (>65%) และ `bmi` เนื่องจากผู้ที่สูบบุหรี่และมีค่า BMI $\ge 30$ จะมีค่าเบี้ยประกันพุ่งสูงขึ้นแบบก้าวกระโดดถึงระดับ 1,400,000+ บาท

## ✍️ ส่วนที่ 2: แบบจำลองการจำแนกประเภทรูปภาพ (Image Classification Model)

### 2.1 แนวคิด ปัญหา และประโยชน์ในการนำไปใช้ (Concept & Problem Statement)
* **ปัญหาที่ต้องการแก้:** พยัญชนะไทย 44 รูป (ก ถึง ฮ) มีสัณฐานวิทยาที่ซับซ้อน ลายเส้นมีความคล้ายคลึงกันสูงในหลายคู่ เช่น การมีหยัก (ข กับ ช), ความยาวหาง (บ กับ ป, ผ กับ ฝ), และทิศทางการม้วนหัว (ด กับ ต)
* **สิ่งที่ต้องการจำแนก:** จำแนกรูปภาพพยัญชนะไทยออกเป็น **44 ประเภท (ก - ฮ)**
* **ประโยชน์ในการนำไปใช้:**
  * **ระบบแปลงเอกสารสแกนเป็นข้อความดิจิทัล (OCR):** แปลงเอกสารราชการและเวชระเบียน
  * **ระบบอ่านป้ายทะเบียนรถยนต์อัตโนมัติ (ALPR):** ตรวจจับหมวดอักษรบนป้ายทะเบียน
  * **สื่อการเรียนการสอนภาษาไทย:** ให้ผู้เรียนฝึกเขียนพยัญชนะบนหน้าจอ และระบบตรวจทานให้ผลย้อนกลับทันที

### 2.2 แหล่งที่มา จำนวนข้อมูล และการแบ่งชุดข้อมูล
* **แหล่งที่มา:** การผสานรวม (Data Fusion) ระหว่างภาพลายมือคนเขียนจริง + ตัวพิมพ์คอมพิวเตอร์ 14 ฟอนต์มาตรฐาน พร้อม Data Augmentation
* **จำนวนข้อมูล:** **22,000 ภาพ** (44 คลาส คลาสละ 500 ภาพ สมดุล 100%) เก็บไว้ใน `data/thai_characters/`
* **การแบ่งชุดข้อมูล (80:20 Stratified Split):**
  * Training Set (80%): **17,600 ภาพ** (400 ภาพต่อคลาส)
  * Test Set (20%): **4,400 ภาพ** (100 ภาพต่อคลาส)

### 2.3 ขั้นตอนการเตรียมภาพ (Preprocessing Pipeline)
1. **Grayscale Conversion:** แปลงภาพเป็น 1 ช่องสัญญาณ
2. **Foreground/Background Standardization:** ปรับให้เส้นหมึกเป็นสีขาว (>0) และพื้นหลังเป็นสีดำ (=0)
3. **Auto-crop Bounding Box:** ตรวจหากรอบล้อมรอบตัวอักษรจริงเพื่อตัดขอบว่างภายนอกออก
4. **Centering & Resizing:** ปรับขนาดตัวอักษรให้อยู่ในกรอบ 20×20 พิกเซล แล้ววางกึ่งกลางภาพขนาด 28×28 พิกเซล
5. **Pixel Normalization:** ปรับสเกลค่าพิกเซลให้อยู่ในช่วง $[0, 1]$

### 2.4 แบบจำลองที่ใช้และการประเมินผล (Model & Evaluation)

| แบบจำลอง (Classification Model) | Architecture | Test Accuracy (4,400 ภาพ) | Macro F1-Score | จุดเด่น |
| :--- | :--- | :---: | :---: | :--- |
| **🧠 Deep CNN (โมเดลหลัก)** | 3 Conv Blocks + BatchNorm + Dropout | **99.14% 🚀** | **0.9912** | **แยกได้ขาดลอย ทั้งตัวพิมพ์และลายมือ** |
| **⚡ Random Forest** | `n_estimators=200`, `n_jobs=-1` | **92.64%** | 0.9258 | เทรนเร็วมาก ใช้เป็น Baseline |
| **🛡️ Support Vector Machine (SVM)** | RBF Kernel, `C=10`, `StandardScaler` | **88.18%** | 0.8827 | โมเดลคลาสสิกตามแล็บ |

* **การแปลความหมายเมตริก:**
  * **Test Accuracy (99.14%):** ทำนายถูกต้องมากกว่า 4,360 ภาพ จาก 4,400 ภาพทดสอบ
  * **Macro F1-Score (0.9912):** ให้น้ำหนักทุกคลาสเท่าเทียมกัน ยืนยันว่าโมเดลทำนายได้ดีสม่ำเสมอทุกพยัญชนะ
  * **การแยกแยะคู่คล้าย:** `ข` ถูกต้อง 99.84%, `ก` ถูกต้อง 99.99%, `บ` ถูกต้อง 99.99%, `ป` ถูกต้อง 100.00%, `ฮ` ถูกต้อง 100.00%

## 💻 3. เว็บแอปพลิเคชันแบบบูรณาการ (Unified 2-in-1 Web Application)

ระบบถูกออกแบบเป็น **2-in-1 Web Portal** โดยมีแท็บให้ผู้ใช้และผู้สอนเลือกทดสอบใช้งานได้อย่างสะดวก:

### 3.1 แท็บที่ 1: Regression App (ทำนายค่าเบี้ยประกันสุขภาพ)
* **การใช้งาน:** เลื่อนแถบระบุ อายุ, เพศ, BMI, บุตร, การสูบบุหรี่, และภูมิภาค แล้วกดปุ่มทำนาย
* **ผลลัพธ์:** แสดงค่าเบี้ยประกันที่คาดการณ์เป็น **บาท (THB)** และเทียบเท่าเป็น **USD ($)** พร้อมประเมินเกณฑ์ BMI และแจกแจงปัจจัยเสี่ยง
* **ตัวอย่างข้อมูลนำเข้า (Preset Examples):**
  1. *วัยรุ่น สุขภาพดี ไม่สูบ (อายุ 19, BMI 22.5, บุตร 0, ไม่สูบ):* ~**73,500 บาท** (~$2,100 USD - เบี้ยต่ำสุด)
  2. *วัยทำงาน มีครอบครัว (อายุ 38, BMI 28.0, บุตร 2, ไม่สูบ):* ~**227,500 บาท** (~$6,500 USD - เบี้ยปานกลาง)
  3. *ผู้สูบบุหรี่ + ภาวะอ้วน (อายุ 45, BMI 35.5, บุตร 1, สูบ):* ~**1,400,000 บาท** (~$40,000 USD - เบี้ยระดับสูงสุด)
  4. *ผู้สูงอายุ ไม่สูบ (อายุ 60, BMI 26.0, บุตร 0, ไม่สูบ):* ~**472,500 บาท** (~$13,500 USD - เบี้ยตามความเสี่ยงอายุ)

### 3.2 แท็บที่ 2: Image Classification App (จำแนกพยัญชนะไทย ก - ฮ)
* **การใช้งาน:** รองรับทั้งการ **อัปโหลดภาพถ่าย** และ **การวาดเขียนด้วยลายมือบนหน้าจอ (Drawing Canvas)**
* **ผลลัพธ์:** แสดงผลการทำนายพยัญชนะไทย 5 อันดับแรก (Top-5 Probabilities) พร้อมภาพขนาด 28×28 ที่ผ่านกระบวนการ Preprocessing
* **ตัวอย่างภาพ:** มีปุ่มภาพตัวอย่างด้านล่างให้คลิกทดสอบได้ทันที
